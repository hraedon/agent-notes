The cross-lineage review was worth it. Codex found two real defects in the
notice work that my own tests missed:

- dedupe state never reset when findings cleared after the notice expired.

names could forge orient lines. All three are fixed with regression tests.

I'm confident in WI-086 and WI-087. Each had an independent pass. I'm less
sure the curation notices will change behaviour. `orient` now surfaces them,
but only as ids and ages (D6 keeps peer text out), so a session still has to
choose to run `msg inbox`. Plan 027's one-month exit check is the real test.
