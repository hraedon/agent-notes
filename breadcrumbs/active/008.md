title: '`agent-notes doctor` loads 270MB embedding model unconditionally'
---
The `doctor` command imports/initializes the embedding model on every invocation, even for checks that don't need embeddings (DSN connectivity, schema version, workspace presence). On a cold cache this adds multi-second startup and 270MB RSS to what should be a fast health check.

Fix: defer the embedding import behind the specific check that needs it (or a `--with-embeddings` flag), so the common case is fast. Probably a single `from .core.embed import ...` moved inside the relevant check function.

Files: likely `src/agent_notes/cli/` doctor command (not touched in this branch). Noticed while working on opencode installer; not in scope for that change.
