Passing `--workspace agent-notes-mcp` when only `default` exists prints `Workspace 'agent-notes-mcp' not found` and exits. The message should list the workspaces that *do* exist and hint at how to create one (or note that workspace names are project-scoped, not repo-scoped — easy mistake given the repo name matches no workspace).

Suggested message:
  Workspace 'agent-notes-mcp' not found. Available: default. Create with `agent-notes workspaces create <name>` (or omit --workspace to use 'default').

Files: workspace resolution path in the CLI (not touched in this branch).
