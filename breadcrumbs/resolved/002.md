`agent-notes-doctor` runs checks top-to-bottom. Check 1 (DSN Reachable) and Check 2 (Schema Up to Date) fail fast when AGENT_NOTES_DSN is unset, but Check 3 still triggers the lazy embedding singleton — observed ~16s waiting for the model load even though DSN was missing.

Doctor is the fast-feedback install-time tool. A health check that takes 16s to report what was already known in the first second discourages re-running during setup, and on a slow connection the model download is a real cost.

## Resolution

Resolved in Phase 7a (commit 1580258). Doctor now tiers checks: prerequisites (DSN, schema) run first; if either fails, heavy checks (embedding load, links audit, vocab integrity) are reported as SKIPPED. Confirmed by test_doctor.py::TestDoctorSkipsOnDsnFailure. Phase 8a further simplified doctor by removing the `breadcrumbs_dir` write-access check (no longer applicable).
