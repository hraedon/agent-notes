## Resolution

Fixed in `src/agent_notes/scripts/doctor.py`. Doctor now tiers checks:
prerequisites (DSN, schema) run first; if either fails, heavy checks
(embedding load, links audit, vocab integrity) are reported as SKIPPED.
A `--skip-embed` flag is also available. The CLI dispatch
(`src/agent_notes/cli/__init__.py:149`) passes `skip_embed` through.

## Observed (historical)

The `doctor` command imported/initialized the embedding model on every invocation, even for checks that didn't need embeddings (DSN connectivity, schema version, workspace presence). On a cold cache this added multi-second startup and 270MB RSS to what should be a fast health check.
