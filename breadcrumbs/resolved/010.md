## Resolution

Fixed in `~/.claude/skills/start/SKILL.md` (Option C — hybrid approach).
The skill now includes a prerequisite check section: it verifies `agent-notes`
is on PATH and `AGENT_NOTES_DSN` is set before running CLI commands. If either
check fails, it falls back to manual orientation using the project's own files
(AGENTS.md, breadcrumbs/, worklog, reflections, plans). The closing note about
CLI contract drift now only applies when the CLI is actually available.

## Observed (historical)

The `start` skill assumes `agent-notes` CLI is globally installed, on `PATH`, and configured with a working `AGENT_NOTES_DSN`. It instructs the agent to run three parallel lookups. When any of these fail, the skill says to file a breadcrumb for contract drift — but the failure mode is often a missing prerequisite, not drift.
